# Team Templates - Manager and Subagents

These optional packets coordinate one short run with one manager and up to three
subagents. They sit beside the project Workbench; they never replace root
`AGENTS.md`, the stable specs, or the generated root `TASKBOARD.md`.

1. Copy `TASKBOARD.md` for the run and fill its goal, acceptance, owners, and
   non-overlapping edit lanes.
2. Give the manager `MANAGER.md` and each subagent `SUBAGENT.md`.
3. Subagents return proof to the manager. The manager is the only writer to the
   run board and the single durable writer for the owning project spec.

This layer is intentionally on-demand, so normal project startup context stays
small.
